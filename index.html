바이어 → 주문 → 제품 → 그때의 사양을 회사 PC 폴더에 기록합니다. 서버·로그인·클라우드 없이 고른 폴더에만 씁니다.

이 브라우저는 폴더 열기(File System Access API, 웹페이지가 PC 폴더를 직접 읽고 쓰게 하는 기능)를 지원하지 않습니다.
Chrome 또는 Edge(데스크톱)에서 열어 주세요.

빈 폴더를 고르면 안에 파일 구조를 새로 만듭니다. 이미 데이터가 있는 폴더를 고르면 그대로 읽습니다.

한 번 연 폴더는 기억합니다. 다음에 열 때는 브라우저의 "허용" 한 번이면 됩니다. 브라우저 보안 규칙이라 그 한 번은 없앨 수 없습니다.

값을 넣은 항목만 조건이 됩니다. 숫자는 같은 값, 글자는 포함.

회사 정보

이 앱을 쓰는 회사. 화면 제목과 작업지시서 머리에 나옵니다. settings.json에 저장됩니다.

데이터 폴더

현재 폴더(안 열림)
들어 있는 것

브라우저는 폴더 이름만 알려줍니다. 전체 경로는 보여주지 못합니다. 브라우저 데이터를 지우면 폴더 연결만 끊기고, 데이터는 폴더에 그대로 남습니다.

여러 PC에서 보기 (동기화 폴더)

이 폴더를 원드라이브·구글드라이브·드롭박스 등 회사가 쓰는 동기화 폴더 안에 두면 다른 PC에서도 같은 기록을 봅니다. 동기화는 그 서비스가 하고, 이 앱은 서버가 없습니다.

주의: 두 PC에서 같은 주문을 동시에 고치면 나중에 저장한 쪽이 남습니다. 주문 1건은 파일 1개라서 서로 다른 주문을 고치는 것은 괜찮습니다.

샘플 데이터

국가 11곳·바이어 27곳(국가별 2~3곳)·제품 40개(호스·피팅·밸브·펌프·필터)·주문 61건 예시를 넣습니다. 수출 정보 값 포함. 시연·인터뷰용입니다.

사양 항목

사양 항목은 폴더의 _schema.json에서 읽습니다. 제품 카테고리마다 사양 항목이 다르고, 수출 정보 항목(라인·주문)도 여기서 정합니다.
